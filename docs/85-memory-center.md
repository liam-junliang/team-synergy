# 记忆中心：可见范围、采集与模型观测

需求 `5CBB6HKH8215XVB1743E` 第 2 修订，冻结基线 `VAJHGYEYAQSNZYD74523` 第 5 版；任务 `RYTBHK85DMP8GP6HEP69`。需求设计来源为平台文档 `Q9PG1YZ817GSGDHDYSBP`。宿主持久安装与诊断由独立 CLI 任务及 `docs/84` 负责，本文不承诺服务器可以检查设备安装。

## 入口与对象

`/account/memory` 保持原路由，头像入口显示“记忆中心”。四个视图分别为总览、项目记忆、个人记忆、采集与处理。已有 `?project=...` 个人来源项目筛选继续进入个人视图，不把来源项目解释为偏好的适用范围。

- 总览分别计数有权项目、已登记资料索引、本人有效及撤回个人记忆、当前有权项目中收到的本人事件，不把这些不同对象相加为一个“记忆总数”。
- 已登记索引按原生资料条目计数，Wiki/Core 是同条目的检索副本。登记状态由后台维护；选择项目后的详情重新读取当前原生版本及对应索引状态，过期索引不能冒充当前来源。
- 项目视图明确选择有权项目，不自动替换无权项目。资料索引沿原页面读取正文；共享讨论/确认来源通过现有 `readSources` 的权限、撤回及替代关系核验，带回原引用与来源修订。讨论不等于共识，确认不等于实施；已落实事实仍须检查原始任务、测试与发布证据。
- 个人视图复用已有账号缓存、来源、历史、乐观版本编辑与撤回。编辑期间其他视图禁用，避免切页丢失草稿。个人记忆所有权仍为账号，失去项目访问权不剥夺本人对私人历史的管理。

## 只读接口与隐私

`GET /account/memory-center` 通过现有认证中间件从会话取得账号。唯一可选查询参数为 `projectCode`；`owner`、`principalCode` 等额外字段和非法项目编码拒绝，不允许客户端指定他人身份。响应使用 `Cache-Control: no-store`，浏览器缓存键同时包含账号和所选项目，账号切换不会复用私人响应。

目录复用 `visibleProjectIds`，项目详情复用 `assertProjectAccess` 及现有索引管理状态、记忆来源读取。系统管理员不绕过项目 ACL，也不能借中心查看其他人的采集事件或私人记忆。采集统计和最近 40 条元数据只查询当前账号，且限制在当前有权项目；指定无权项目返回拒绝，不静默改选项目。个人计数按最后修订、包含已撤回条目，既有私人管理接口不变。

响应包含采集编码、项目、session/event 标识、状态、尝试次数、入队/更新时间、可关联回执编码及安全错误分类。不会返回 `payload_json`、`result_json`、会话正文、来源哈希、原始服务错误、引擎配置 JSON、模型端点或任何凭据。未知错误归一为 `memory_capture_failed`。

## 采集、整理与投影分别表示什么

状态按持久化 `memory_capture_jobs` 展示 `pending`、`processing`、`completed`、`skipped`、`needs_clarification`、`failed`；终态更新时间作为最近处理时间，不能解释为模型调用时间。已完成事件可能来自重放、明确采纳等无需模型的路径，不反推它一定调用了 LLM。

服务接收开关来自当前 `TSP_MEMORY_ENABLED`。开关开启只说明服务器配置，不能证明某设备的 Hook 已安装、受信、重启或发出事件。安装状态和设备本地队列始终为 `unknown`，由客户端对应诊断工具核对。0 事件显示“尚未收到事件”；不显示“已自动启用”或直接宣称“未安装”。不自动导入历史会话，不向业务账号创建偏好来填充空状态。

资料原文、共享来源、私人记忆、采集事件和投影作业是不同对象。投影成功既不增加一份新的语义记忆，也不证明方案采纳、实施或发布。

## 当前进程模型配置与观测

公共响应只显示当前进程实际使用的 `TSP_MEMORY_PROVIDER`、`TSP_MEMORY_MODEL` 及各自显式/默认来源。原默认仍为 `ollama` / `hub-qwen2.5:latest`，不会用部署意图替代实际配置；配置改变并重启后读取新值。模型名只接受有界安全字符展示，非法配置显示不可用标识，不回显端点、密钥或运行配置原文。会话整理器与 Tencent 检索引擎内部模型属于不同链路。

`memory-observability.ts` 只在当前服务进程保存实际模型请求的 attempt、响应 JSON 解析 success、请求/解析 error 计数和时间。预判拦截、明确采纳、缓存重放不会因此增加请求次数；显式注入的纯分类探针不算当前服务请求。响应解析成功之后的业务分类或来源校验仍可能要求澄清，成功计数不意味着生成长期记忆。

此观测不持久化任何输入、输出、账号、端点或凭据。它是全服务聚合，只有系统管理员响应中包含 `model.observation`；普通成员不接收这些计数或时间，不能从中心推断其他账号的私人活动。管理员界面明确标注“全服务、仅当前进程”，不冒充当前账号历史。进程重启、其他实例和独立探针进程的调用均未知；尚无持久化逐事件模型调用证明。

## 验证边界

核心回归覆盖未登录、owner 覆盖参数、无权项目、其他账号采集隔离、管理员仍只读本人事件、未知错误脱敏、当前原生修订与过期索引区分、私人编辑/撤回计数，以及 provider/model 的显式/默认和密钥/端点不泄露。组件回归覆盖真实视图切换、索引不重复计数、空采集诚实提示、账号缓存隔离及既有私人编辑流程。

数据库测试必须通过 canonical 55432 测试集群的全新租约，禁止用业务库做测试或写合成偏好。实际页面验收使用现有数据，只读核对 920×671 附近的布局及操作。当前实现不新增 schema 或 npm 依赖，不修改 CLI/MCP 检索、宿主事件格式或提炼判断语义。
