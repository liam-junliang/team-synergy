## 状态机

| 状态族 | 已观察机制 | 资格与限制 |
| --- | --- | --- |
| Task | draft→ready→assigned→running→self_tested→submitted→verified→closed为主要成功路径；failed/blocked等另有恢复分支 | 转换依据Task状态机和具体守卫；不等于强制不同自然人，详M06。 |
| Run | active/suspended/preparing/transferred/completed/failed/cancelled为独立持久化枚举 | 枚举不是线性流程；领取、交接、暂停、恢复及终结守卫详M06/M07，不套用Task状态。 |
| Handover | 提议、接收、取消、失效与源执行暂停/恢复分别记录 | 取消或过期不自动恢复源Run，详M07。 |
| Intake | draft/ready/applying/applied/partial/cancelled/stopped；attempt单独记状态 | 同键重放与新键续传不同；停止保留已提交项，详M11。 |
| 文档Agent | 排队、运行、待审、采用/拒绝/失败/取消 | 修改稿生成不自动采用；当前文档修订与候选依据须匹配，详M12。 |
| 代码理解 | preparing/indexing/awaiting_agent/validating/uploading/succeeded/failed/cancelled为契约状态 | 发布与选择视图分离，提交与草稿分离；枚举不保证每条CLI路径都会经过每个中间状态，详M14。 |
