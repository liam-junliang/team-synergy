# ADR-0012：受控运维入口与敏感审计边界

- 状态：Accepted
- 日期：2026-10-23
- superseded_by: null

## 背景

批次 D 需要指标、审计出口、本机管理员恢复和磁盘回收，同时不得让普通成员读取全局运维信息，不得让凭据进入审计或失败现场。平台现有审计需要真实 principal，设备授权事务先锁请求再锁用户。

## 决策

- Prometheus scrape 与审计导出要求有效系统管理员 Bearer；保持 CLI 与 Web 身份边界。指标标签限定固定方法、路由模板和状态，不使用账号、项目、路径参数、SQL或错误消息。
- 审计导出按微秒精度时间起点、固定最大 ID、ID 游标有界读取。所有应用审计写入复用 insertAudit 的结构校验与脱敏边界；历史审计不静默改写，导出时再次脱敏。
- 管理员恢复仅经显式开启的本机 CLI 和服务器数据库权限，不提供 HTTP 入口。审计 principal 使用被恢复的真实管理员 ID，payload 明示本机操作者与 actor_authenticated=false，避免伪装用户会话。
- 恢复是罕见维护操作：先对 device_authorization_requests 取 EXCLUSIVE 表资源锁，再锁目标用户并吊销未兑换授权、设备、会话和租约。这只在维护窗口短暂串行授权变更，不新增全局 advisory 键；防止请求锁→用户锁与恢复流程倒置。普通 API 不采用该全表锁。
- Agent 的所有运行文件在子进程回收后删除；可选保留仅含固定失败码/时间，不含 session、home、prompt 或 stderr。启动清理限于专用根下可识别目录，不跟随链接或删除活动 run。
- 既有迁移摘要作为不可改写基线；新增迁移拆分 expand/contract，CONCURRENTLY 走事务外的手工 DDL 与运维记录，不能伪造 Drizzle head。

## 验证

以真实数据库回归授权批准/兑换与重置的并发顺序、旧 grant 不可重放；验证管理员导出权限、微秒/时区过滤、脱敏、指标标签与慢查询日志不含秘密；受限进程成功/失败/取消/超时后清理，以及迁移违规门禁。
