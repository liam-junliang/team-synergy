# Web 国际化与顶部切换入口

## 使用方式

Web 支持简体中文（`zh-CN`）与英文（`en-US`），覆盖登录、账号、团队、项目、计划、需求、设计、任务、文档、交接、缺陷和架构设计。

登录页、首次改密页及工作台顶部提供地球图标。点击打开语言菜单，当前语言带勾选标记；支持键盘上下键、Home、End 和 Escape。选择后立即生效，关闭菜单并恢复按钮焦点。

语言偏好保存在当前浏览器的 `tsp:web:locale`。首次访问按浏览器支持的语言选择，无匹配时使用简体中文；已保存的选择优先。多个标签页同步偏好，禁止本地存储时仍可在当前页面切换。日期、数字、页面标题和 `html.lang` 同步更新。

## 文案与内容边界

- 界面文案、状态、操作、加载/空状态及固定目录译名随语言变化。
- 状态徽标和下拉选项使用简短译名，例如 `Draft`、`Ready`、`Review`、`Queued`、`Retest`；说明性文字放在帮助文本中。
- 文档类型标记在两种语言下统一显示 `doc`、`api`、`diagram`，包括文档树、阅读页头与新建表单。
- 项目名称、成员名称、用户目录、文档正文、版本说明及上传的 HTML/图片/图源保持原文。固定目录按 `system_role` 显示译名，不能按中文名称猜测目录身份。
- 已知服务错误按稳定错误码提供英文提示，保留错误码及原始详情；未知错误保留服务返回的消息，避免丢失诊断信息。
- 切换语言不重建工作台、不清空选择和表单草稿。新建模板使用创建时语言；既有模板和图源不随语言重写。
- draw.io 使用打开编辑器时的语言；打开中的画布保持原会话，下一次打开采用新语言，避免丢失未保存编辑。

## 项目快捷切换

项目页顶部的项目名称是切换入口。列表使用服务端按当前用户项目成员身份筛选的项目，支持项目名、团队名及编码搜索。项目、团队名称保持原文。

切换到另一个项目时保留当前菜单及合法子页签，例如需求文档或项目架构页；清除原项目的文档、目录、交接记录、新建操作等详情参数，并重建该项目的工作台，防止旧详情或编辑状态带入新项目。再次点击当前项目只关闭列表。

列表包含加载、失败重试、空结果、当前项目和归档标记。键盘上下键可遍历结果，Escape 关闭并恢复入口焦点。窄屏下顶部操作单独成行，项目按钮允许收缩，弹层从左侧展开。

## 维护约定

使用现有 React 和原生 `Intl`，未增加依赖。

- `apps/web/src/i18n.ts`：语言状态、纯翻译函数、偏好持久化、格式化和固定目录名称。
- `apps/web/src/useLocale.ts`：通过 `useSyncExternalStore` 订阅语言；无需给页面添加语言 `key`。
- `apps/web/src/locales/`：按功能拆分的中文源键与英文译文，`core.ts` 保存公共文案。
- `apps/web/src/apiError.ts`：服务错误的显示层翻译，不修改 API 协议。
- `LanguageSwitcher.tsx`、`ProjectSwitcher.tsx`：两个独立的顶部入口。

新增固定文案应写成完整句子并使用命名参数，例如 `t('任务：{count}', { count })`。不要拼接数量与中文量词，不要把用户正文传给翻译函数。数字参数会本地化；编码或版本号应作为字符串传入，避免千分位改变标识形式。

同一中文在动作和状态里含义不同时使用不同源键，例如“通过评审”译为 `Approve`，“通过”状态译为 `Passed`。词典查找只接受自身属性，未知键原样回退。

不要在模块初始化时执行翻译；在渲染、回调或动态 getter 内取值。缓存计算需要显式依赖语言，日期助手支持第三个 `Locale` 参数。纯展示子组件可由已订阅的父组件触发更新。

## 验证

自动化覆盖语言解析、存储异常、跨标签页同步、插值完整性、英文文案覆盖、日期、固定目录、原文保留、语言切换保留草稿、图表会话语言、项目搜索及跨项目路由清理。现有业务测试仍需通过。

验收命令：`pnpm --filter @team-synergy/web test`、`pnpm typecheck`、`pnpm lint`、`pnpm build`。浏览器目测和真实焦点交互需要另外记录结果，不能用源码或 SSR 测试替代。
