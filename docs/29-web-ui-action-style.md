# Web 操作控件风格标准

本文件定义操作层级；字体、颜色、表单、响应式和弹窗统一遵循 [Web UI 设计与实现规范](34-web-ui-design-system.md)。下列尺寸是应遵循的目标，不表示所有旧工作台已经完成迁移。

## 1. 目标

操作控件的视觉强度必须与它在当前页面中的决策优先级一致。页面级操作、弹窗提交和卡片内部操作不得只因为“都能点击”而使用同一种按钮外观。

## 2. 操作层级

| 层级 | 使用场景 | 样式 | 约束 |
| --- | --- | --- | --- |
| 主操作 | 页面当前流程唯一的推荐下一步 | `ui-button ui-button-primary` | 一个操作区原则上只出现一个 |
| 强操作 | 深色工具栏、需要高对比的完成动作 | `ui-button ui-button-strong` | 不与主操作并列竞争 |
| 常规操作 | 新建、编辑、保存、弹窗取消 | `ui-button` 加对应语义变体 | 32px 高、12px、500 字重、8px 圆角、有边框和轻阴影 |
| 紧凑操作 | 卡片中仍需明确按钮感的操作 | `ui-button ... ui-button-compact` | 28px 高、12px、500 字重、8px 圆角；仍属于显式按钮 |
| 局部上下文操作 | 分区标题、卡片标题或时间线记录中的关联、撤回等辅助动作 | `ui-context-action` 加对应变体 | 28px 高、12px、500 字重、8px 圆角、透明边框、无阴影；使用图标和短标签 |
| 纯图标操作 | 关闭、刷新等含义稳定的工具动作 | `ui-icon-button` | 必须提供 `aria-label` 和 `title` |
| 局部分段选择 | 资料类型、局部视图等互斥选项 | `ui-segmented` / `ui-segmented-item` | 12px、500 字重；当前项使用 `aria-pressed`，不承担提交表单动作 |

## 3. 局部上下文操作

- 默认状态保持低强调，不得使用裸蓝色粗体文字模拟按钮。
- 建设性操作使用 `ui-context-action-accent`，例如“关联”。对象名称由所在分区标题提供，按钮标签保持简短，完整语义放在 `aria-label` 与 `title`。
- 普通辅助操作直接使用 `ui-context-action`，例如列表项的“归档/恢复”。当操作关系到内容状态时默认常驻，不能只依赖鼠标悬停出现。
- 当前筛选使用 `ui-context-action-selected`，通过边框、浅背景与 `aria-pressed` 同时表达选中状态；不得使用缺少状态语义的临时灰色胶囊。
- 破坏性操作使用 `ui-context-action-danger`。默认仍为中性色，只有悬停时转为玫红；真正执行前必须进入明确的危险确认弹窗。
- 图标用于说明动作类型，不使用字符 `+`、`×` 等符号替代语义图标。
- 同一操作区中的按钮高度、字号、圆角和图标尺寸必须一致；不得在组件内临时拼接另一套尺寸。

## 4. 语义与可访问性

- 图标使用 `aria-hidden="true"`；按钮自身提供可辨识名称。
- 只显示“关联”等短标签时，`aria-label` 必须包含对象，例如“关联想法”“关联文档”。
- 颜色不作为唯一语义来源；危险操作同时依赖图标、文字和确认对话框。
- 所有操作控件必须有键盘焦点环、禁用状态和足够的点击区域。

## 5. 实现入口

样式契约位于 `apps/web/src/index.css`，回归断言位于 `apps/web/tests/button-style-system.test.mjs`。新增操作样式前，应优先复用现有语义类，避免在业务组件内复制完整的 Tailwind 样式串。

不得用 `!important` 修补控件字体；不要增加会覆盖 Tailwind 工具类的无层级 `font: inherit`。标准按钮和局部分段选择保持 12px / 16px、500 字重，字体与表单目标值以 [完整 UI 规范](34-web-ui-design-system.md) 为准。
