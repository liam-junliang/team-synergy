# 系统管理台与平台接入配置

日期：2026-10-18。

## 入口和职责

系统管理员登录后默认进入 `/admin/teams`。管理台提供「团队项目管理」「用户管理」「系统配置」三个菜单，使用系统管理标识，不展示业务项目切换器和 Agent 入口。普通成员继续使用 `/teams`，访问管理页面或管理接口会被拒绝。

系统管理员的全局治理权与项目业务权限分开。管理台可以查看团队、项目的基本信息和数量，维护名称、项目说明及归档状态；这些操作不会自动加入团队、改变负责人，或开放需求正文、任务、文档等项目内容。显式打开项目深链接仍按原项目成员权限检查。CLI 浏览器授权链接保留原目标，不被管理员默认首页重定向覆盖。

`/account` 是个人账号页；平台用户管理位于 `/admin/users`。管理员可以搜索账号、创建普通用户、重置密码、禁用或恢复普通用户，并管理授权设备和登录会话。管理台不提供提升系统管理员身份的操作。已注销、正在注销及系统管理员账号不能通过普通用户启停按钮操作；恢复禁用用户不会恢复旧设备凭据、会话或任务租约，成员需要重新登录。

## 团队项目管理

- 团队与项目分别列出，支持按名称或编码搜索、分页，项目可以按团队及归档状态筛选。归档项目只在系统管理的项目目录显示，由系统管理员恢复。
- 展示负责人、成员数量及归属团队，列表接口同时返回创建者信息。管理页不会把系统管理员显示为这些资源的负责人。
- 修改团队名称、项目名称/说明、归档或恢复项目时必须填写管理原因，事务内记录变更前后值和操作者。
- 项目修改使用 `base_snapshot` 检查打开表单时的版本。别人已修改项目时返回冲突，重新读取后再操作，防止旧表单意外恢复已归档项目。
- 项目负责人执行常规归档前，须结束准备中、执行中或挂起的 Run。系统管理员可以选择强制归档并填写原因。同一事务结束这些 Run 和未完成的交接，撤销对应的执行租约，保留任务、历史及已提交的证据。恢复项目后，未交付且中断的任务可重新领取。成员在本机独立启动的 Agent 进程由其本机管理，平台拒绝旧 Run 继续写入。

## 系统配置

在 `/admin/settings` 配置成员机器可以访问的地址：

| 配置 | 示例 | 留空行为 |
| --- | --- | --- |
| Web 公开地址 | `https://team.example.com` | 使用成员当前浏览器站点 |
| API 公开地址 | `https://team.example.com/api` | 使用有效 Web 地址加 `/api` |

Web 地址只支持站点根地址；API 地址可以带路径。正式访问使用 HTTPS，HTTP 仅允许本机回环地址。不接受账号密码、查询参数、片段或命令字符。配置不会修改服务器监听端口、DNS、证书、反向代理或已有 CLI 本地登录配置，部署方必须先确保地址可访问。

CLI 接入页通过同源、已登录请求读取公开地址，再生成安装命令与 `tsp auth login --api ... --web ...`。Web/API 分开部署时，浏览器授权会打开配置的 Web 入口。用户令牌不会随配置请求发往自定义域名。未配置地址时保留当前访问地址的开发体验；加载失败时提示重试，不生成猜测的连接命令。

配置使用 `base_revision` 防止多人同时修改时相互覆盖；成功保存使 CLI 指引缓存失效，并记录操作者及前后地址。空白可以清除覆盖值。系统配置不存储密码、登录令牌或任意服务器目录。

## CLI 发布状态

配置页显示 Windows、macOS、Linux 的 x64/arm64 共六种发布目标，附 CLI 版本、运行时版本和发布标识，支持手动刷新。状态来自服务端发布清单，并过滤缺失或大小不符的包；安装器下载后仍校验 SHA-256。

安装包由部署流程构建和发布，此页面不上传包或执行服务器命令。发布目录通过 `ACP_CLI_DIST_DIR` 配置。构建、反向代理和安装步骤见 [CLI 分发、浏览器授权与设备会话](45-cli-distribution-device-sessions.md)。

## 数据与接口

迁移 `0038_system_settings.sql` 新增单例配置表，不修改现有团队/项目归属、文档版本、用户密码或设备身份。管理接口要求有效 Bearer 会话，并重新检查系统管理员身份；写操作检查管理员账号是否正在注销，并在事务中锁定对应数据。

| 接口 | 用途 |
| --- | --- |
| `GET /admin/teams`、`GET /admin/projects` | 全局元数据检索与分页 |
| `PATCH /admin/teams/:code`、`PATCH /admin/projects/:code` | 带原因的管理变更 |
| `GET /admin/settings`、`PUT /admin/settings` | 读取和版本化保存系统配置 |
| `GET /platform/client-config` | 登录成员获取公开接入地址 |
| `POST /users/:code/enable` | 恢复可重新登录的禁用普通用户 |

## 回归检查

验证普通用户和未登录请求不能读取或写入管理数据，管理员无需加入团队即可查看全局元数据但不能读取未授权业务内容；验证搜索、分页、审计原因、旧版本冲突、运行中归档保护、注销账号保护及旧凭据不复活。配置覆盖默认地址、独立 API/Web 地址、清空、并发写、非法 URL 和指令注入。前端覆盖中英文导航、管理员默认入口、授权深链接、账号状态及六种发布目标。
